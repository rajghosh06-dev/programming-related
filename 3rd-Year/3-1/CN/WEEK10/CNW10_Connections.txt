ROUTING CONFIGURATION DIFFERENCE:
The PDF describes static routes using "ip route". However, the saved .pkt router
configurations contain RIP network statements:
- network 1.0.0.0
- network 2.0.0.0
- network 3.0.0.0

The saved configurations do not contain the static "ip route" commands shown
in the PDF. They also do not show "version 2" or "no auto-summary".
Therefore, do not assume the current saved .pkt configuration is the same as
the static-routing instructions in the PDF.

FTP / TFTP SERVER ADDRESS:
Server0 IP address: 2.2.2.2
Use this address from PC0 or PC2 when connecting to the server.

FTP CLIENT COMMANDS (as described in the PDF):
From PC0:
1. Create A.txt using Desktop > Text Editor and save it.
2. Open Desktop > Command Prompt.
3. Enter:
   ftp 2.2.2.2
4. Use the FTP username/password configured on Server0.
5. At the ftp> prompt, upload:
   put A.txt
6. Exit:
   quit

From PC2:
1. Open Desktop > Command Prompt.
2. Enter:
   ftp 2.2.2.2
3. Log in with the same FTP credentials.
4. Download:
   get A.txt
5. Exit:
   quit
6. Verify:
   dir
   type A.txt

TFTP CLIENT COMMANDS (as described in the PDF):
From PC0, upload:
tftp -i 2.2.2.2 put A.txt

From PC2, download:
tftp -i 2.2.2.2 get A.txt

Verify the downloaded file:
dir
type A.txt
