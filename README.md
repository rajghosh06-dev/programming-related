## 🚀 How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/rajghosh06-dev/programming-related.git
   ```
2. Navigate to the desired folder.
3. Compile or run the program using the appropriate compiler/interpreter:
   - **C/C++** → `gcc filename.c -o output && ./output`
   - **Java** → `javac filename.java && java ClassName`
   - **Python** → `python filename.py`

    > (Commands may vary slightly depending on your OS and environment.)
